Institutional buying tracking • Weekly / Fortnightly / Monthly Top 5 • 100% free NSE data • Roz auto-update
📖 PART 1 — Dashboard kya karta hai, section by section

Ye dashboard NSE ke official free data se track karta hai ki institutions (MF, Insurance, Banks, FII) kis stock me paisa daal rahe hain. Data ke 2 sources:

  • Bulk/Block Deals — jab koi institution ₹10Cr+ ya 0.5%+ equity ka bada trade karta hai, NSE usko publish karta hai (client ka naam ke saath!)
  • Delivery Volume (bhavcopy) — har stock ki roz ki delivery quantity. Institutions delivery-based buying karte hain, isliye delivery % jump = institutional accumulation ka signal. Isi se teeno Top 5 rankings banti hain (saare 500 Nifty stocks scan hote hain)
Section Kya dikhata hai Final kab hota hai
🏦 FII vs DII Aaj ka net investment (₹ Cr) + pichhle 15 sessions ki bars — market ka overall mood Roz (market ke baad)
🔥 Insti Accumulation (7D) Bulk/block deals se — kis stock me institutions 7 din me net buy/sell kar rahe hain (₹Cr leaderboard) Roz
🚀 WEEKLY TOP 5 500 stocks me delivery buying ka sabse bada weekly % change (vs 7 din pehle) Har Friday night ✅
🗓️ FORTNIGHTLY TOP 5 500 stocks me delivery buying ka sabse bada 15-din % change (vs 15 din pehle) Har month ki 16th ✅
📅 MONTHLY TOP 5 500 stocks me delivery buying ka sabse bada monthly % change (vs pichhla month-end) Har month-end ✅
📋 Bulk & Block Deals Har deal ki detail — kaun client (INSTITUTION/PROMOTER/OTHER badge), kitna, kis price pe. Filters + date history Roz
🗂 Sector Flow (7D) Kis sector me institutions net paisa daal/nikal rahe hain Roz
📌 Important samajhne wali baatein:
1. Top 5 sections me "IN PROGRESS" dikhna normal hai — rankings roz refresh hoti hain, final date pe "FINAL ✅" badge lagta hai. Aapko daily dekhna hai, isliye daily data chahiye — final sirf tag hai.
2. Har Top 5 row me Delivery% change bhi dikhta hai (green/red) — agar quantity badhi hai lekin delivery% gira hai, to sirf zyada trading thi, institutional buying nahi. Dono columns dekh kar judge karo.
3. Har row me Insti Deals overlay — agar us stock me bulk/block deals hue to unka net ₹Cr dikhta hai (cross-validation).
4. Har section ka apna ⬇ CSV download button hai.
5. Kisi bhi stock pe click → TradingView chart khulta hai.
6. Use kaise karo: Top 5 stocks ko apne GTF zone dashboards (strict-pure-stocks / all-timeframe-stocks) se cross-check karo — institutional buying + GTF demand zone = strong setup.

🛠️ PART 3 — GitHub pe step by step (10 minute)
STEP 1 — Naya repo banao
  1. github.com kholo → login karo → top-right ➕ icon → New repository
  2. Repository name me likho: insti-tracker
  3. Public select karo (Private me pages free me kaam nahi karta)
  4. "Add a README file" ka checkbox KHALI chhodo
  5. Create repository dabao
STEP 2 — Files upload karo (dono tarike, koi bhi use karo)
Tarika A — Website se (aasaan):
  1. Naye repo me dikhega: "uploading an existing file" link (ya Add file → Upload files)
  2. Workspace folder insti-tracker/ kholo → saari files aur folders select karke drag & drop karo us box me
  3. Neeche Commit changes (green button) dabao
Tarika B — Git commands (laptop pe folder download karke):
git clone https://github.com/heartaltafhussain-lgtm/insti-tracker.git
cd insti-tracker
# workspace ke insti-tracker folder ki saari files is folder me copy karo
git add .
git commit -m "Insti Tracker v1.0 - weekly/fortnightly/monthly top5"
git push origin main
STEP 3 — Workflow permission do (sabse zaroori setting!)
  1. Repo me jao → Settings tab → left sidebar me Actions → General
  2. Neeche scroll karo → section "Workflow permissions"
  3. "Read and write permissions" select karo ✅
  4. Save dabao
⚠️ Ye setting ke bina auto-scan chalega, data banayega, lekin commit nahi kar payega — dashboard kabhi update nahi hoga. Ye miss mat karna!
STEP 4 — GitHub Pages on karo
  1. Repo Settings → left sidebar me Pages
  2. "Deploy from a branch" select karo
  3. Branch: main → Folder: / (root)
  4. Save dabao
  5. 1-2 minute me upar dikhega: "Your site is live at https://heartaltafhussain-lgtm.github.io/insti-tracker/"
STEP 5 — Pehla scan manually chalao
  1. Repo me Actions tab kholo
  2. Left side me "daily_insti_scan" pe click
  3. Run workflow → green Run workflow button dabao
  4. 2-3 minute wait karo → 🟢 green tick aayega (yellow chalta hua hai, red = fail)
Agar red aaya: workflow pe click → job pe click → Run Insti Scanner step kholo — error yahan dikhega. Screenshot le kar mujhe bhej do.
